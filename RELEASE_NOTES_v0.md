# Release Notes: v0.1.0-alpha

## What this is

The first public alpha of Evidence-Driven Project State: an architecture-first set of Agent Skills for evidence-heavy project state, method research, falsifiable design tests, and optional knowledge retrieval.

## Compatibility scope

- **Hermes Agent:** primary tested environment for the originating workflow.
- **OpenClaw:** primary compatibility target; runtime-parity testing remains in progress.
- **Other Agent Skills hosts:** format target only until host-specific smoke cases pass.

No statement here implies vendor endorsement or identical behavior across hosts.

## Release boundary

This is an independent personal open-source contribution. The contributor's affiliation with TJAD AI专班 / 量子城市专班 is biographical context only and does not make this an official institutional publication.

This repository is a research software artifact, not a paper or preprint. It contains public-safe development regressions but no held-out benchmark, private research protocol, manuscript, participant data, or client source material.
## Notable controls

- domain-aware authority, source status, and attribution;
- metric-definition isolation;
- project facts separated from Agent proposals;
- named-person method research separated from persona or style imitation;
- fixed-input regression after Skill changes;
- public Skills de-identified from private research cases;
- CI validation for structure, frontmatter, links, private residue, and eval JSON.

## What it is not

- a universal project-management platform;
- a replacement for professional review, client authorization, or statutory sign-off;
- a claim that every host or domain has equivalent results;
- permission to redistribute copyrighted source books, project files, or confidential data.
