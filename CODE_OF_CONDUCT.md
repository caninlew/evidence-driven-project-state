# Code of Conduct

## Our Standard

We want this project to be useful, rigorous, and welcoming.

Contributors and maintainers are expected to:

- discuss ideas in good faith
- challenge claims with evidence, not hostility
- distinguish critique from personal attack
- avoid overstating what the framework can do
- respect domain expertise and review boundaries

## Unacceptable Behavior

Examples of unacceptable behavior include:

- harassment or personal insults
- intentionally misleading claims about project capabilities
- publishing confidential or unsafe material in issues or pull requests
- pressuring maintainers to remove explicit safety or approval boundaries

## Scope

This code of conduct applies to repository discussions, issues, pull requests, and other project communication channels.

## Enforcement

Maintainers may remove, edit, or reject contributions that violate this code of conduct or weaken the project's evidence and safety standards.
