## Short Pitch

This repository helps teams turn messy project material into controlled project state before moving into research, design, execution, or handoff.

## Long Pitch

Evidence-Driven Project State is a framework for teams that need more than task tracking. It separates source observations, current facts, stakeholder statements, open questions, conflicts, and bounded tasks, so downstream work is based on explicit state instead of mixed assumptions. The first domain pack is optimized for architecture and design workflows, and the underlying method is intended to transfer to consulting, product, research, and other knowledge-intensive projects. Equivalent cross-domain behavior remains to be evaluated.

## First Public Release Scope

Recommended v0 public scope:

1. core framing and documentation
2. architecture domain pack
3. one project-root template
4. machine-readable smoke-test definitions

Do not wait for full cross-domain coverage before publishing.

## Messaging Guardrails

Always say:

- architecture-first, not architecture-only
- evidence-driven, not fully automatic
- state-based, not generic task tracking
- domain-extensible as a design goal, not a claim of completed cross-domain validation

Avoid saying:

- fully autonomous
- no setup needed
- replace all project management tools
- works for every project equally well
