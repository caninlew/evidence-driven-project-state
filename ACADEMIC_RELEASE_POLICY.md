# Academic release policy

## Purpose

This policy separates open-source development from later scholarly claims. It is designed to preserve public priority and reproducibility without publishing private evidence, a complete manuscript, or a held-out evaluation set prematurely.

## Public repository boundary

The public repository may contain:

- versioned Skills and schemas;
- public-safe documentation and development fixtures;
- validation scripts and release notes;
- clearly labeled exploratory or descriptive status statements.

Keep outside the public repository until a deliberate research release:

- manuscript drafts and reviewer correspondence;
- complete research protocols and unreleased hypotheses;
- held-out cases, answer keys, and tuning history;
- participant or client data;
- copyrighted or confidential source collections;
- unreported quantitative results.

## Claims discipline

Do not describe development cases as a benchmark, a successful demonstration as an effect size, or format compatibility as behavioral equivalence. Separate:

1. what the repository contains;
2. what has been technically validated;
3. what is a research hypothesis;
4. what a later study measures;
5. what remains a professional or human decision.

## Publication workflow

1. create a versioned public software release and persistent archive;
2. preserve a private or embargoed, time-stamped study protocol before held-out evaluation;
3. run the frozen protocol and record all deviations;
4. prepare an anonymized manuscript and a separate title page when required;
5. disclose repository releases, preprints, funding, conflicts, data availability, and substantive generative-AI use according to the target venue's current policy;
6. publish a preprint only as a deliberate decision, and disclose its identifier during submission;
7. release additional data or results only after rights, confidentiality, and peer-review timing have been checked.

Repository authorship, software contribution, research authorship, and institutional affiliation are separate questions. Record actual contributions and obtain any institutional or third-party clearance required for public release.
